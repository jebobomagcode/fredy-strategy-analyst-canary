# Fredy Strategy Analyst — public research preview

[Open the viewer](https://jebobomagcode.github.io/fredy-strategy-analyst-canary/) · [Beta URL](https://jebobomagcode.github.io/fredy-strategy-analyst-canary/beta/)

Both URLs contain the same reviewed October 29, 2026 static build. Type any supported Binance USD-M perpetual symbol. Choose **Review 4H + 1H + 15m** for a one-click, independently receipted three-timeframe research screening; select timeframe tabs to inspect existing loaded histories without extra requests. You can still refresh an individual 4H, 1H or 15m chart manually. Market requests run in your browser against the official Binance futures API when it is accessible in your region.

The optional research layer is off by default until you explicitly enable it or click the three-timeframe review button. S1–S4 are FSA project research categories, not Coach-authored strategy branches or Coach-issued signals. Geometric observations are research only. The application does not generate qualified entries, stops, targets, fills or profitability claims; missing, stale or conflicting evidence must remain INSUFFICIENT DATA.

## Privacy and scope

- Read-only charts; no orders, account connection, backend AI service or automated trading.
- No private reports, Messenger exports, source lessons, credentials or private repository history are included.
- Provider restrictions, HTTP 451, CORS, timeouts and data errors are displayed as unavailable/unverified. Availability is not guaranteed across regions.
- An updated chart is not a newly qualified trading assessment. Original report integration and genuine source-receipt capture remain separate development work.
